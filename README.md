# Exercícios de MongoDB - Bancos de Dados Não Relacionais

Repositório dedicado aos exercícios práticos da disciplina de **Bancos de Dados Não Relacionais**, desenvolvidos durante o **7º semestre** do curso de **Engenharia de Software** na **Faculdade Anhanguera**.

## Sobre a Disciplina e o Conteúdo

Este repositório armazena scripts, consultas e atividades práticas focadas no ecossistema **NoSQL** com ênfase no **MongoDB**. Os exercícios abordam desde operações básicas de CRUD (Create, Read, Update, Delete) até consultas avançadas, modelagem de dados orientada a documentos e pipelines de agregação.

## Tecnologias e Ferramentas Utilizadas

* **[MongoDB](https://www.mongodb.com/)**: Banco de dados NoSQL orientado a documentos.
* **[MongoDB Compass](https://www.mongodb.com/products/compass)**: Interface gráfica oficial para gerenciamento e inspeção visual dos dados.
* **MongoDB Shell (`mongosh`)**: Ferramenta de linha de comando para execução de queries e comandos administrativos.

## Estrutura do Repositório

```text
├── Exercicio-mongodb/           # Scripts e consultas desenvolvidas nas aulas (.js / .json)
├── modelagem/            # Modelos conceituais e estruturação de documentos JSON/BSON

Como Executar os Exercícios
Certifique-se de ter o MongoDB e o MongoDB Compass (ou o terminal mongosh) instalados e configurados em sua máquina.

Inicie a instância do seu banco de dados local ou utilize uma conexão em nuvem (como o MongoDB Atlas).

Abra o MongoDB Compass ou o terminal mongosh, crie o banco de dados/coleção correspondente ao exercício e execute os comandos ou importe os arquivos fornecidos nas pastas.
